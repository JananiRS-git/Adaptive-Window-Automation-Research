## 🔬 About the Research

**The Comprehensive Analysis of Adaptive Window Automation using Machine Learning and Edge AI** presents an intelligent approach to adaptive window automation by integrating **Machine Learning, Edge AI, IoT, and automated control**.

The research explores how intelligent sensing and edge-based decision-making can be used to improve automated window operation under changing environmental conditions.

The work focuses on developing a smarter and more responsive window automation system while reducing the need for manual intervention.
